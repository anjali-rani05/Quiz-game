

# Quiz Game

A responsive, interactive quiz app built with **HTML, CSS, and JavaScript** featuring **20 challenging questions**, live score tracking, instant feedback, and a final results screen. Perfect for practicing **DOM manipulation** and **event handling**.

---

## Features

- Start, quiz, and result screens  
- 20 difficult, logic-based questions  
- Live question counter and progress bar  
- Instant correct/incorrect answer feedback  
- Final score with performance message  
- Restart quiz functionality  
- Fully responsive design for mobile and desktop  

---

## How to Use

1. Clone the repository or download the project  
2. Open `index.html` in a browser  
3. Click **Start Quiz** to begin  
4. Answer the questions and view your final score  
5. Click **Restart** to play again
